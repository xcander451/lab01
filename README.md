# Лабораторная работа №1

## Предварительная обработка и очистка данных

### Цель работы

Изучить основные методы анализа, предварительной обработки и очистки данных с использованием библиотеки Pandas.

### Описание работы

В лабораторной работе использовался датасет Bank Marketing. Сначала была изучена структура набора данных: количество строк и столбцов, типы признаков, количество уникальных значений и основные статистические характеристики.

Затем была выполнена проверка данных на наличие пропущенных значений и полных дубликатов. Также был проведён анализ категориальных признаков, после чего их значения были приведены к единому формату с помощью удаления лишних пробелов и перевода текста в нижний регистр.

Для числовых признаков были исследованы выбросы. Для их обнаружения использовались два метода:

* межквартильный размах IQR;
* метод стандартных отклонений Z-score.

После обнаружения выбросов была выполнена их обработка с помощью метода `clip()`. Значения, выходящие за допустимые границы, заменялись ближайшими граничными значениями.

### Результат

В результате работы были изучены и применены основные методы предварительной обработки данных. Датасет был проанализирован, категориальные признаки нормализованы, а выбросы обнаружены и обработаны.

### Вывод

Предварительная очистка данных является важным этапом анализа и машинного обучения. Она помогает устранить дубликаты, привести значения к единому формату и уменьшить влияние аномальных значений на результаты дальнейшего анализа.
